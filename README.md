# MyWorld
Watch a post-apocalyptic world that lives on it's own.

## Сборка (Windows)

Нужны Visual Studio 2026 с компонентами «Разработка классических приложений на C++» и «Средства CMake для C++», а также git. Зависимости (raylib, Dear ImGui, rlImGui, EnTT, FastNoiseLite) скачиваются при первой конфигурации.

```powershell
scripts\build.ps1          # собрать (RelWithDebInfo)
scripts\build.ps1 -Run     # собрать и запустить
scripts\build.ps1 -Test    # собрать и прогнать тесты
```

Либо открыть папку в Visual Studio или VS Code (CMake Tools) и выбрать пресет `vs`.

Исполняемые файлы — в `build\bin\<конфигурация>\`:

- `living_world.exe [--seed N]` — окно с миром. Каждый seed — своя карта. Для отладки: `--hours H` прокручивает мир на H игровых часов до показа (ночь, погода, зима), `--view X Y ZOOM` ставит камеру (метры и пиксели на метр), `--path X1 Y1 X2 Y2` прокладывает путь между точками (метры), `--nav-graph` показывает граф навигации, `--screenshot FILE.png` сохраняет снимок окна и выходит;
- `lw_headless.exe [--seed N] [--ticks N]` — прогон симуляции без окна, печатает сводку по карте, дату, погоду, людей, зомби и орды, летопись и хеш состояния. `--people N`, `--zombies N`, `--animals N`, `--flocks N` — сколько людей, зомби, животных и стай птиц (по умолчанию 300, 400, 160 и 24). `--climate` — сводка погоды и температуры за игровой год по сезонам. `--paths N` — замер поиска пути на N парах точек трёх видов, с `--optimal` — ещё и сравнение с оптимальными путями.

## Управление

| Действие | Ввод |
|---|---|
| Зум | колесо мыши |
| Панорама | правая или средняя кнопка мыши, WASD, стрелки |
| Показать весь мир | Home |
| Пауза | Space |
| Скорость x1 / x10 / x100 | 1 / 2 / 3 |
| Выбрать человека, зомби, животное, стаю птиц или здание (инспектор) | ЛКМ |
| Проверка пути: начало / цель | Ctrl+ЛКМ / Ctrl+Shift+ЛКМ |

## Дорожная карта

У каждого пункта указан **effort** — уровень усилия рассуждений Claude Code, на котором его стоит делать: `low`, `medium`, `high`, `xhigh`, `max`. Чем выше уровень, тем дороже ошибка в этом пункте для следующих этапов (детерминизм, архитектура, баланс поведения).

Правило: один этап за раз, после этапа проект собирается и запускается.

### Этап 1. Каркас — готово
- [x] CMake, зависимости через FetchContent, скрипт сборки — `medium`
- [x] Окно, камера с зумом и панорамой — `low`
- [x] Фиксированный тик, скорости x1/x10/x100, бюджет кадра — `high`
- [x] Стабильные id сущностей, собственный RNG с потоками — `high`
- [x] Прогон без окна, хеш состояния, тест детерминизма — `medium`
- [x] Панели времени и статистики — `low`

### Этап 2. Генерация 2D-карты — готово

- [x] Вода: море, озёра, реки — `medium`
- [x] Леса и типы местности — `low`
