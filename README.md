# MyWorld
Watch a post-apocalyptic world that lives on it's own.

## Сборка (Windows)

Нужны Visual Studio 2026 с компонентами «Разработка классических приложений на C++» и «Средства CMake для C++», а также git. Зависимости (raylib, Dear ImGui, rlImGui, EnTT, FastNoiseLite) скачиваются при первой конфигурации.

```powershell
scripts\build.ps1          # собрать (RelWithDebInfo)
scripts\build.ps1 -Run     # собрать и запустить
scripts\build.ps1 -Test    # собрать и прогнать тесты
```

Либо открыть папку в Visual Studio или VS Code (CMake Tools) и выбрать пресет `vs`.

Исполняемые файлы — в `build\bin\<конфигурация>\`:

- `living_world.exe [--seed N]` — окно с миром. Каждый seed — своя карта. Для отладки: `--hours H` прокручивает мир на H игровых часов до показа (ночь, погода, зима), `--event drop` сбрасывает груз на старте (до `--hours`) и открывает его в инспекторе, `--view X Y ZOOM` ставит камеру (метры и пиксели на метр), `--path X1 Y1 X2 Y2` прокладывает путь между точками (метры), `--nav-graph` показывает граф навигации, `--3d`, `--orbit YAW PITCH`, `--camera fly|shoulder` — начать с 3D, орбиты под углом, полёта или вида из-за плеча выбранного (`--select ID`), `--outbreak D` — вспышка через D игровых суток (по умолчанию 7, 0 — не по расписанию), `--phase NAME` — сразу перевести мир в фазу (outbreak, panic, collapse, survival), `--director` — режим «Сериал»: кино в 3D во весь экран, камеру ведёт режиссёр по самой интересной сюжетной линии, окна спрятаны (этап 12а.7; Esc — выход, F11 — снова), `--screenshot FILE.png` сохраняет снимок окна и выходит (`--screenshot-delay S` — через S реальных секунд работы окна);
- `lw_headless.exe [--seed N] [--ticks N]` — прогон симуляции без окна, печатает сводку по карте, дату, погоду, людей, зомби и орды, летопись и хеш состояния. `--people N`, `--zombies N`, `--animals N`, `--flocks N` — сколько людей, зомби, животных и стай птиц (по умолчанию 300, 0, 160 и 24: мир начинается с мирной жизни). `--no-peace` — без мирной жизни (профессий, денег, магазинов, водопровода) и без сценария, как до этапа 7.2: мир сразу живёт по правилам выживания. `--outbreak D` — вспышка зомби-вируса через D игровых суток (по умолчанию 7, 0 — не по расписанию), `--phase NAME` — сразу перевести мир в фазу (peace, outbreak, panic, collapse, survival); в сводке — строка `scenario`: фаза, когда начиналась каждая, потери, приток зомби. `--stories` — сюжетные линии из летописи (этап 12а): сколько каких, чем кончились, самые длинные — со всеми событиями. `--foresight` — предвестия (этап 12а.2): что по ходу прогона виделось «вот-вот» (месть, орда к поселению, обращение, гонка за грузом, кража), сколько сбылось, насколько заранее и как точен был срок. `--cast` — главные герои (этап 12а.3): кто, когда и через кого вошёл в состав и каким событием связан, вес биографии, сколько линий, чем кончилось. `--climate` — сводка погоды и температуры за игровой год по сезонам. `--daily` — строка на каждые игровые сутки: фаза мира, живые, зомби, звери, погибшие по причинам, еда, патроны, покупки и деньги, сколько людей ещё выходит на работу и в скольких магазинах работают (по ней подбирается баланс). `--social` — в конце список социальных событий по порядку: спасения, слухи, группы, дележ, обмены, кражи у своих, побеги, нападения, месть, убийства людьми (из них читаются истории). `--events` — журнал ивентов: начало, конец, кто что забрал из грузов; `--event-schedule` — временное расписание ивентов (по умолчанию выключено: в мирное время грузы не падают); `--event drop H` — сбросить груз через H игровых часов. `--paths N` — замер поиска пути на N парах точек трёх видов, с `--optimal` — ещё и сравнение с оптимальными путями.

## Управление

| Действие | Ввод |
|---|---|
| Зум | колесо мыши |
| Панорама | правая или средняя кнопка мыши, WASD, стрелки (отпущенная на ходу катится по инерции) |
| Показать весь мир | Home |
| Вид сверху / 3D | V |
| 3D: вращение и наклон | ПКМ + мышь, Q/E, R/F; СКМ — панорама |
| Свободный полёт | G; WASD, E/Q — выше/ниже, Shift — быстрее, ПКМ + мышь — осмотреться, колесо — скорость |
| Из-за плеча выбранного | T; ПКМ + мышь — осмотреться, колесо — ближе/дальше |
| Подсказка по клавишам | F1 |
| Пауза | Space |
| Скорость x1 / x10 / x100 | 1 / 2 / 3 |
| Выбрать человека, зомби, животное, стаю птиц или здание (инспектор) | ЛКМ |
| Проверка пути: начало / цель | Ctrl+ЛКМ / Ctrl+Shift+ЛКМ |

## Дорожная карта

У каждого пункта указан **effort** — уровень усилия рассуждений Claude Code, на котором его стоит делать: `low`, `medium`, `high`, `xhigh`, `max`. Чем выше уровень, тем дороже ошибка в этом пункте для следующих этапов (детерминизм, архитектура, баланс поведения).

### Этап 7. Ивенты и рассказчик
Номера подэтапов — те же, что в сообщениях коммитов. В 7.1 вошёл первый вид ивента — падение припасов.

Мир не начинается с апокалипсиса. Сначала всегда мирная жизнь: люди работают, ходят в магазин,
живут семьями, заводят дружбы и обиды. Потом начинается сценарий (первый — зомби-вирус), и катастрофа
развивается реалистично: нулевой пациент, вспышка, непонимание, попытки властей удержать порядок,
паника, коллапс, выживание. Все системы этапов 4–6 (нужды, страх, бой, память, отношения, группы,
кражи, месть) остаются и включаются естественно — от того, что происходит в мире, а не с первой минуты.
Зомби — бывшие жители, с именами и прошлым.

### Этап 12а. Режиссёрское наблюдение — «как сериал»
Отдельная кнопка «Режиссёр» (и `living_world --director`): смотреть мир как сериал — с героями, сюжетными линиями, напряжением и развязками, а не перескоками по событиям. Работает и локально, и в клиенте-наблюдателе; для стриминга — главный режим. Номера подэтапов — те же, что в сообщениях коммитов; 12а.1–12а.6 сделаны в виде сверху, с 12а.7 режим «Сериал» — только в 3D.
- [x] 12а.1. Сюжетные линии: из летописи собираются арки (кража → обида → месть; дружба → группа → предательство; укус → лихорадка → обращение; ивент → гонка за грузом), у арки — участники, завязка, нарастание, ожидаемая развязка — `high`
- [x] 12а.2. Предвкушение: режиссёр смотрит не только на свершившееся, но и на то, что вот-вот случится (мститель идёт к обидчику, орда приближается к деревне, укушенный скрывает рану, двое идут к одному грузу) и успевает к кульминации — `high`
- [x] 12а.3. Главные герои: несколько персонажей с богатой биографией, к которым режиссёр возвращается («эпизоды»); новые герои вводятся через связь с уже знакомыми — `medium`
- [x] 12а.4. Темп и монтаж: держать кадр на герое, чередовать напряжение и тишину (быт, костёр, разговор), параллельный монтаж двух линий, ускорять время в затишье, не дёргать камеру — `medium`
- [x] 12а.5. Операторская работа: планы (общий — орда у деревни, средний — группа, крупный — герой из-за плеча), плавные пролёты, медленный облёт в драматичные моменты, замедление в кульминации — `medium`
- [x] 12а.6. Подписи и титры: имя героя и одна строка, что он хочет и почему («John Miller идёт мстить Peter Green за украденное ружьё»), «ранее в сериях» при возвращении к герою, итог эпизода («Mary Cole погибла, защищая дом») — `medium`

Отзыв после 12а.6: смотреть пока неинтересно и непонятно. Камера перелетает от точки к точке, подписи говорят языком системы («орда идёт к …»), показывают незнакомых, человек у дома просто стоит. Решение: **кино — только в 3D**. Режим «Сериал» прячет все окна и меню и сам переходит в 3D; вид сверху остаётся для наблюдения и отладки, кино в нём нет. Режиссёр — не диспетчер «где сейчас интереснее», а шоураннер: эпизоды из сцен, монтаж, ракурсы, рассказчик, сцены в домах. Из 12а.1–12а.6 остаются линии, предвестия, герои, темп и тексты титров; операторская часть вида сверху (12а.5) заменяется кинокамерой.
- [x] 12а.7. Режим «Сериал»: кнопка и `--director` — полный экран в 3D, все окна ImGui и меню скрыты, широкий кадр с полосами, титры и подписи поверх кадра своим оформлением, выход — Esc (возврат к прежнему виду и окнам); кинокамера: позиция, цель, фокусное расстояние, плавность — управляется только режиссёром, не уходит в рельеф и стены — `high`
- [x] 12а.8. Сцены и монтаж (шоураннер): эпизод на 5–10 реальных минут следит за 2–3 главными героями, у него линия A и побочная B; единица показа — **сцена** (место, участники, о чём она, минимальная длина, не перебивается ради «поинтереснее»); вместо перелётов — склейка через затемнение и вводный титр места и времени («Старое Село, дом Миллеров. Вечер»), установочный общий план → ближе; скучное время вырезается скачком («Три часа спустя», мир между сценами — x100); правило «на экране только знакомый зрителю или угроза знакомому»; перебивка с драматической иронией («Орда, которую мы видели утром, в двух километрах от дома Мэри. Она ещё не знает»); в конце эпизода клиффхэнгер, в начале — «ранее в сериях» — `high`

Отзыв после 12а.8: сцены долгие, однотипные и скучные. Человек стоит у реки, а камера бесцельно кружит вокруг; человек умер — и начинается пустое ожидание, пока он встанет, одна и та же картинка. Нет повествования: на экране только кадр и что делает персонаж. Скачок времени — по сути то же ускорение и идёт слишком долго. В титрах служебные слова («кульминация», «нарастает»). Люди не двигаются по действию: отдыхающий просто стоит. Текстуры мерцают. Мир вне леса пуст: поля голые, реки плоские. Решение: **пустых моментов быть не должно** — сцена длится, пока в ней что-то происходит, ожидание заполняется монтажом; камера двигается только с причиной; скачок времени — мгновенная склейка; со зрителем говорят языком истории, не системы; анимация на каждое действие в нескольких вариантах; мерцание и пустота мира — подэтапы 11.8 и 11.9. Порядок работы: 12а.9 → 12а.10 → 11.8 → 12а.11 → 11.9 → 12а.12 → дальше по номерам. Подэтапы после 12а.8 перенумерованы (прежние 12а.9–12а.13 стали 12а.12, 12а.13, 12а.11, 12а.14, 12а.15).
- [x] 12а.9. Без пустых моментов: у сцены есть вопрос и ответ (чего хочет герой, что мешает, чем кончилось) — она кончается, когда ответ получен или ничего не меняется дольше нескольких секунд, а не по таймеру длины; ожидание (тело вот-вот встанет, герой спит, идёт долго, стоит у воды) не показывается целиком, а заполняется монтажом и возвращается к моменту перемены: реакция близких (нашли тело, узнали о смерти, горюют, спорят, кто виноват), что в это время делают другие герои эпизода, параллельная линия B, угроза знакомому на подходе, короткие красивые кадры-паузы (рассвет и закат таймлапсом, надвигающаяся гроза, туман над рекой, орда вдали, дым над деревней) — паузы только как связка между событиями, не вместо них; к развязке ожидания (встаёт из тела, просыпается, доходит) камера успевает заранее; ни одна сцена не повторяет предыдущую по месту, плану и действию подряд — `high`. Сделано (`ui/Showrunner.*`): сцена следит за переменами и кончается по ответу или через 5 с без перемен; ожидания откладываются и камера возвращается за 12 с до развязки (тело встаёт — точно по `Corpse::turnsAt`, предвестие, сон, долгий путь), скачок мотает ровно до неё; монтаж ожидания — реакция близких на гибель знакомого, другие герои, кадры-паузы (рассвет и закат таймлапсом, гроза, туман над водой, орда вдали, дым — низкий неподвижный план `ShotPlan::vista`); без повторов подряд, выдохшаяся сцена не возвращается, пока в ней ничего не изменилось; знакомое место — без установочного плана. «Спорят, кто виноват» — нет повода в симуляции, на потом.
- [x] 12а.10. Скачки и язык кадра: скачок времени — мгновенная склейка: под чёрным титром («Три часа спустя») мир проматывается без отрисовки за 1–2 реальные секунды (как промотка в панели «Время», `SimDriver::requestSkip`), на экране не видно ускорения; камера не двигается без причины — никаких облётов и кружения ради движения: статичный кадр или движение за героем, наезд к важному, отъезд в финале; из титров и подписей убраны служебные слова (стадии линии «завязка», «нарастание», «кульминация», «развязка», названия видов линий и предвестий) — только человеческий текст о героях и событиях — `medium` Сделано: скачок — под чёрным кадром без отрисовки мира, не дольше 1,5 с (цепочка ночью — 3 с, титр от её начала), часов на чёрном нет; общий план неподвижен, крупный переставляется только когда видна спина героя, смена крупности — склейка встык, заслонили — переход на чистый курс (`CameraController::cinemaBlocked`), отъезд в финале (`Showrunner::finale`); человеческие заголовки линий и предвестий (`storyHeadline`, `omenHeadline`) вместо видов и стадий, убраны «Кульминация», «Передышка», «Будни», «Итог сцены».
- [ ] 12а.11. Анимации на каждое действие, в нескольких вариантах (выбор по id и характеру, смена позы раз в несколько секунд, плавные переходы; только облик, симуляция не меняется): отдых — сидит на земле, крыльце, лавке, лежит, прислонился к стене, потягивается; еда и питьё — сидя, на ходу, у костра, пьёт из бутылки, зачерпывает из реки ладонями; сон — в кровати, на земле, свернувшись; работа по профессии — фермер копает и жнёт, продавец за прилавком, полицейский в обходе, врач осматривает; обыск — открывает шкафы, роется на корточках; сбор — наклоняется к кустам, складывает в сумку; общение — жесты, кивки, смех, спор, объятие; дележ и обмен — протягивает вещь; бой — замах, удар, прицел, выстрел с отдачей, перезарядка, падение; ранение — хромает, держится за рану, перевязывается; горе — на коленях у тела; страх — оглядывается, пятится, прячется; ожидание — переминается, оглядывается; зомби — шаркают, раскачиваются, едят тело, бьют в дверь, обращение — тело дёргается и поднимается; звери — пасутся, чешутся, прислушиваются; поворот головы к тому, на кого смотрит; значки эмоций над головой в важные моменты — `high`
- [ ] 12а.12. Ракурсы и композиция: планы — общий, средний, крупный, через плечо, «восьмёрка» в разговоре, двойной план; правило третей (герой на линии третей, свободное место — по взгляду и движению); правило 180° (противники держат свои стороны кадра, направление движения сохраняется между склейками); нижний ракурс для угрозы, верхний — для беспомощности, голландский угол в панике; движение камеры только мотивированное — наезд, проезд за героем, панорама, отъезд в финале; кадр «через проём», виньетка и цвет по настроению; план выбирается по смыслу сцены (разговор, погоня, засада, горе, быт) — `high`
- [ ] 12а.13. Рассказчик: текст повествования из летописи, памяти и отношений вместо статусов — знакомство с героем при первом появлении (кто он, чем живёт, что с ним было), мотив сцены, связки между сценами («Тем временем вор, о котором говорили Миллеры, уже в лесу»), реплики-характеристики («Джон не умеет прощать») — `medium`
- [ ] 12а.14. Сцены в помещениях: квартиры, дома, базы — комнаты, стены, двери, окна и мебель коробками (как модели 11.3) по планировке из id здания, детерминированно и только облик, симуляция и хеш не меняются; камера заходит внутрь и снимает по правилам 12а.12, не схемой-разрезом (ближние к камере стены и крыша прячутся); люди встают по действию; семейные сцены из того, что уже есть в мире (семья ест дома в одно время — общий ужин); мотивированный свет из окна, от лампы, костра; позже на этих комнатах — баррикады и базы этапа 14; нехватку поводов для домашних сцен (спор из-за еды, ночное дежурство, сборы перед бегством) добавить в симуляцию по итогам — `high`
- [ ] 12а.15. Уникальные диалоги: реплики героев в кадре (облачка над головой и строка в подписи), собранные из их памяти, отношений, черт и нужд — не шаблонные фразы, а про конкретных людей и события («Ты бросил Сару у колодца, Питер. Я помню.»); тон зависит от характера и настроения, повторы отсекаются; в важные моменты можно сочинять реплики языковой моделью вне симуляции (не влияет на детерминизм) — `high`
- [ ] Рассказчик в связке: в затишье подбрасывает события туда, где идёт линия героя — `medium`
- [ ] Голосование зрителей за ивенты и героя как команды серверу — `high`
